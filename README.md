# UDP-Protocol

# Overview
This project is designed to help you meet the course outcomes regarding reliable data transfer, flow control, and congestion control. You will move beyond simply using the network to building the protocols that make the network functional.￼
    
In this project, your team will develop a custom application-layer protocol to transfer files reliably between two remote servers: "Moon" and "Mars" with your user accounts there. While the underlying transport layer will be UDP (which is connectionless and unreliable), your task is to implement logic that ensures 100% data integrity, even if the network loses or delays packets.
